[청첩장 웹에 올리는 방법]

이 폴더에는 파일이 다섯 개 있어요.
  index.html   청첩장 본체
  wedding.ics  "캘린더에 저장" 버튼이 쓰는 일정 파일
  bgm.mp3      배경음악(직접 녹음한 목소리)
  thumb-photo.jpg   카카오톡 등으로 주소를 보냈을 때 나오는 미리보기 사진

다섯 파일을 같은 폴더에 둔 채로, 무료 웹 호스팅(예: Netlify, GitHub Pages, Cloudflare Pages)에 올리면
평소 쓰는 웹 주소(https://...)가 생겨요. 그 주소로 열면 아래 기능이 켜져요.
  - 배경음악(bgm.mp3) 재생
  - 전화·문자 버튼 → 휴대폰 전화/문자 앱으로 바로 연결
  - 캘린더 저장 → 갤럭시는 삼성 캘린더, 아이폰은 기본 캘린더

※ 파일을 컴퓨터에서 그냥 더블클릭해 열면 음악은 재생되지 않아요(웹 주소로 열어야 해요).
※ 웹 주소를 아는 사람은 누구나 볼 수 있어요. 계좌번호와 전화번호가 들어 있으니 주소는 필요한 분께만 보내세요.
